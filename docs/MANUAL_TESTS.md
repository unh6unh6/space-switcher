# 수동 테스트 체크리스트

권한·단축키·Spaces 동작은 자동으로 검증할 수 없다. 변경한 영역의 항목을 골라 사용자에게 번호 목록으로 제시하고 결과를 받는다.
SPEC §7을 바탕으로 개발 중 발견한 항목을 더했다. 새 버그를 고치면 재발 확인 항목을 여기에 추가한다.

자동 점검(먼저 실행): `swift scripts/smoke.swift` — 패널 열림(<100ms) · Sticky 유지 · Esc 닫힘

## Spaces / 메뉴바
- [ ] 데스크탑 전환 시 메뉴바 이름이 1초 이내 갱신
- [ ] 데스크탑 추가/삭제/순서 변경 후 메뉴 목록이 올바름 (메뉴를 열 때마다 재조회)
- [ ] 전체화면 앱 Space는 목록에 없음, 전체화면 위에서는 메뉴바에 "전체화면"
- [ ] (#15) 설정 → 일반 → 메뉴바 표시: 이름만 / 번호+이름 / 점 / 점+이름 / 번호만 즉시 반영, 이름 최대 길이 10·20·30자
