# 결정 기록

SPEC.md와 다르게 가거나 SPEC이 열어 둔 것을 정한 기록. **여기가 SPEC보다 우선한다.**
새 결정은 맨 아래 표에 날짜와 이유를 붙여 추가한다.

## 배포 · 서명

| 항목 | 결정 | 이유 / SPEC과 차이 |
|------|------|-------------------|
| Apple 계정 | 유료 Developer Program **없이** 진행, 공증 안 함 (2026-09-29) | SPEC은 Developer ID + 공증. 비용 없이 나+지인용. 공증은 #6 |
| 서명 | 자체 서명 인증서 **`SpaceSwitcher Signing`** 하나로 Debug·Release·DMG 전부 서명 | TCC(손쉬운 사용)가 서명 기준이라, 고정 인증서면 재빌드·업데이트해도 권한 유지. 인증서를 바꾸면 모든 사용자가 권한을 다시 줘야 함 |
| 번들 ID | `io.github.unh6unh6.SpaceSwitcher` | 바꾸면 이름·설정·권한이 초기화되므로 고정 |
| 저장소 | 공개 `unh6unh6/space-switcher`, 브랜치 `main` (2026-10-14 `SpaceSwitcher`에서 이름 변경) | 지인이 Releases에서 받을 수 있게. 커밋 이메일 공개는 사용자가 수락. 소문자-하이픈은 GitHub 관례; 예전 주소는 GitHub가 자동 연결하므로 같은 계정에 `SpaceSwitcher` 저장소를 다시 만들지 말 것. 앱 이름·번들 ID·DMG·cask 토큰은 그대로 |

| 대상 | macOS 14+, Universal(arm64 + x86_64) | 지인 Intel 맥 대응 |

## 동작

| 항목 | 결정 | 이유 / SPEC과 차이 |
|------|------|-------------------|
| 스위처 첫 선택 | **현재 데스크탑**이 기본, 설정에서 "직전 데스크탑" 선택 가능 (2026-09-30) | SPEC은 직전(MRU). 사용자 선호로 변경 |
| 키 꾹 누름 | 단축키 K의 autorepeat는 **무시** (2026-09-30) | 실수로 여러 칸 넘어가는 것 방지. 방향키 autorepeat는 이동 허용 |
| Sticky 키 입력 | 패널을 key window로 만들지 않고 **이벤트 탭이 계속 처리**. 인라인 이름 편집 때만 앱 활성화 | 활성화하면 사용자 앱의 포커스를 뺏고 Space가 바뀔 수 있음 |
| 전체화면 앱 Space | 목록에서 제외 (MVP) | SPEC 그대로. 포함은 #3 |
| 다중 모니터 | 메인 디스플레이만 (MVP) | SPEC 그대로. 지원은 #2 |
| 단축키 제약 | ⌃/⌥/⌘ 중 1개 이상 + 일반 키. Esc·Return·↑↓·R·1–9는 금지 | Shift만이면 대문자 입력을 가로챔. 금지 키는 열린 패널의 조작 키와 충돌 |
| 이름 | 최대 30자(grapheme), 앞뒤 공백 제거, 빈 값=삭제. 사라진 uuid의 이름은 보관 | SPEC §3.4 그대로 |
